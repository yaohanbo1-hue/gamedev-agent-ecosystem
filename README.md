## 🚀 快速开始

### 单Agent使用
```markdown
你是一个 [Agent角色]，请帮我完成 [具体任务]

示例：
你是一个 LevelDesigner，请为Roblox Obby游戏设计10个关卡
```

### 多Agent协作
```markdown
请帮我完成一个完整的游戏项目，包括：
1. 市场调研和竞品分析
2. 游戏设计和关卡规划
3. 核心系统开发
4. 美术资源制作
5. 测试和发布
```
